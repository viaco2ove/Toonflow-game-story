
# 图片上传接口 /game/uploadImage：

curl -X POST 'http://192.168.31.66:60002/game/uploadImage' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpZCI6MSwibmFtZSI6ImFkbWluIiwiaWF0IjoxNzg4NTg1NzYwLCJleHAiOjE4MDQxMzc3NjB9.-bhItf-JIKr3HtN3mzLzT56JSNeOqrdYs8aPWPqBdpY' \
  -d '{
    "projectId": 1,
    "type": "role",
    "fileName": "test.png",
    "base64Data": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABAAAAAYAAjCB0C8AAAAASUVORK5CYII="
  }'

返回：

{
  "code": 200,
  "data": {
    "path": "http://127.0.0.1:60002/1/game/role/<uuid>.png",
    "filePath": "/1/game/role/<uuid>.png"
  },
  "message": "ok"
}

参数说明：
- type："role" 或 "scene"（控制子目录）
- fileName：可选，扩展名可从这里取（没传就从 base64 data URL 的 mime 推断
- base64Data：完整的 data:image/xxx;base64,... 字符串
- projectId：可选；不传会落到 /user/{userId}/game/{type}/
