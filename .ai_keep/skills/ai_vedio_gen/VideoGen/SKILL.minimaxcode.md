# minimax code 视频生成工具
视频生成工具（MiniMax Video/视频生成/gen_videos / batch_text_to_video / batch_image_to_video），支持：

文生视频 — 纯文字描述生成
图生视频 — 用本地图片作为首帧
可选 6s 或 10s 时长，分辨率 768P / 1080P

## MiniMax Video
开发者 WebGuHui (MiniMax Video adaptation); OpenChatCut contributors
本地优先的视频编辑工作室：多轨剪辑、字幕、特效、Agent 与视频导出。基于 OpenChatCut（AGPL-3.0-or-later）移植。

## 视频生成
开发者 MiniMax
使用 H3、H3 Max 或 H2.3 通过 mcode-tools Connector 创建视频，支持文生视频、关键帧和完整多模态参考素材。H3 Max 极速生成，约 20 秒出片。
