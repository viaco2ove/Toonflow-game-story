# 故事里的res 文件夹
## res 文件夹:构思过程
这个文件夹不是最终产物而是中间产物
故事构思阶段的产出-》res 文件夹下

## 一个故事的目录结构
破局 - 从冷落走到瞩目/  
├── STORY.md                    # 故事主文件（世界观、简介、章节列表）  
├── STORY.old.v1.md             # 旧版故事文件  
├── .env                        # 环境配置（API 地址、账号等）  
│  
├── chapters/                   # 章节文件  
│   ├── chapter_1.md  
│   ├── 。。。
│  
├── roles/                      # 角色设定文件  
│   ├── role.list.md            # 角色列表  
│   ├── 顾泽.md                 # 主角（用户）  
│   ├── 顾子航.md               # 反派  
│   ├── 。。。
├── res/                        # 构思过程
├── avatars/                    # 角色头像  
├── image/                      # 其他图片  
├── python/                     # Python 脚本工具  
└── tasks/                      # 任务相关  

## 故事的初期产物应该在res文件夹下    
构思完再去建故事的其他文件和文件交
